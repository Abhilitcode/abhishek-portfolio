# Project memory

## Product intent & audience

- Personal portfolio website for Abhishek Khale, an AI/ML Engineer and Generative AI Developer.
- Audience: recruiters, hiring managers, peers in AI/ML.
- Single-page scrolling portfolio with section-based navigation.

## Brand personality & voice

- Premium, futuristic, professional.
- Visually impressive but minimal clutter; confidence and technical credibility over playfulness.

## Visual design & UX direction

- Dark navy/black background; electric blue and cyan accents.
- 3D-inspired visuals: rotating 3D orbit in hero, card tilt-on-hover, subtle glowing effects.
- Smooth scroll-triggered fade-in animations for sections.
- Responsive across desktop and mobile.
- Reusable section/card components; clean component structure.
- Profile photo handled via initials placeholder until real image provided.

## Decisions, constraints & rationale

- Built with React + Vite + Tailwind CSS per user request; no additional UI/icon packages beyond lucide-react.
- Projects split into three categories: Generative AI, Machine Learning, Deep Learning.
- Experience includes TCS and DaveAI; Education lists B.Tech Computer Engineering, CGPA 9.84.
- All unspecified personal data (email, LinkedIn, GitHub, photo, project details, dates, university, certifications, achievements, exact skill list) kept as placeholders — user explicitly forbade inventing details.
- Initial skills list uses common AI/ML tools as a starting point, flagged for user confirmation/correction.

- Need from user: profile photo.
- Need from user: project details, role titles, employment dates, university name.
- Need from user: actual certifications and achievements.
- Need from user: confirmed/updated technical skills list.
